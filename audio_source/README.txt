Put your original Azan recordings in this folder.

- Any common format is fine: .mp3, .m4a, .wav, .ogg, .aac, .flac
- Any file name is fine (Claude will convert and rename them for the app).
- If you have a full Azan and a short Azan, name them so it is clear which is which,
  for example "full azan.mp3" and "short azan.mp3".

Licence / permission:
Please also write below (or in a separate text file here) where each recording came
from and what permission you have to include it in the app, for example:
  - "Recorded by me / my mosque, permission given by ..."
  - "Downloaded from <website>, licence <name>, link <url>"
The app will only bundle recordings that may be redistributed.

Note: the original files in this folder are NOT uploaded to GitHub (they can be large).
The converted, size-optimised copies used by the app are stored in app/src/main/res/raw.
